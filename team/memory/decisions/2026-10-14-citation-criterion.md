# Decision: Citation criterion for the conference layer (2026-10-14)

Founder, Oct 14, 2026: "The idea is even if they just say a scripture it should be Added."

- A talk connects to a scripture if the speaker references it in any form:
  a formal footnote citation, a direct quote, OR a spoken mention/allusion.
  All three count and get added; there is no "formal citations only" tier.
- This criterion is the standing definition for the conference layer's
  dataset whenever it is built, by whatever lawful route.
- Practical note (recorded, not a ruling): footnote-based extraction only
  catches formal citations. Catching spoken mentions requires transcript
  level data, which is exactly the judgment layer the Scripture Citation
  Index already embodies. The criterion therefore matches the SCI's scope
  and raises the value of the permission route relative to a DIY build.
