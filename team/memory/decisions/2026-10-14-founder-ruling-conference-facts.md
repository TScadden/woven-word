# Decision: Founder ruling — conference layer builds on citation facts (2026-10-14)

Supersedes the research gate FAIL recorded in
`2026-10-14-board-run-8-conference-citation-research-preserved.md`
(the gate's findings stand as research; its "do not build" conclusion
is overridden by this ruling).

## The ruling
Founder (Tyson), Oct 14, 2026, verbatim: "Use it in building the app
but we won't ever actually add anything copyrighted so we don't need
to ask permission." The permission request drafted earlier is NOT
being sent.

His basis, confirmed to him by Rusty as the correct legal core before
he decided: citation FACTS — talk title, speaker, conference
year/session, cited scripture references — are not copyrightable
material (Feist). The app will never contain talk text or any other
copyrighted content. Rusty's risk read (compilation-copying vs
fact-recording, and the Church site's terms as a separate wall) was
delivered to the founder in full before this ruling; the decision is
his, made with that read in hand.

Related founder decisions already on record:
- Citation criterion (`2026-10-14-citation-criterion.md`): formal
  citations, quotes, and spoken mentions all count as connections.
- Talk links (Oct 14, 2026): talk surfaces link OUT to the talk in
  Gospel Library instead of hosting anything — "instead of putting
  the actual talk there we can add a link to Gospel Library to read
  it there."

## Method limits (Rusty's, binding on HOW the studio works)
1. Facts only, per the citation criterion.
2. NO scraping of churchofjesuschrist.org — its Terms of Use prohibit
   automated copying and redistribution; that route stays closed
   absolutely.
3. NO extraction or redistribution of the Scripture Citation Index
   app database file (the wholesale-copy route; its extractors
   themselves label it non-redistributable).
4. The dataset is assembled by recording citation facts from publicly
   accessible published sources (the SCI's public web index is the
   reference source for the facts), in the app's own schema, at
   ordinary-use pacing — respectful request rates, no hammering, no
   circumvention of any access control. Attribution to the Scripture
   Citation Index is kept in the app wherever its facts inform the
   data.
5. The pipeline is reproducible and documented (sources, method,
   coverage, counts). If full coverage cannot be assembled inside
   these limits, ship the coverage honestly reached and state the
   gap plainly — never escalate methods to close it.
