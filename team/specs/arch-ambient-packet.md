## What changes

## What does NOT change (binding)

1. **The brightness discipline from the fix round stands.** The
   founder's complaint was "the arch is too bright"; additive blowout
   stays banned. No `BlendMode.plus` in the ambient path.
2. **Selection behavior is untouched.** `MiniSelectionPainter`
   (rainbow per the founder's Oct 14 ruling), the faint path, and
   every selection overlay keep shipped behavior. This package
   changes the look only until a selection exists.

## Brightness contract — bounded by construction (lesson 31)

- Keep `BlendMode.srcOver`. A srcOver composite over black is a
  convex combination of the stroke colors; WCAG luminance of the
  composite therefore cannot exceed the brightest single stroke
  color's luminance. Bound each stroke and the field is bounded.
- **Luminance-clamp every sweep color before drawing:** compute the
  color's WCAG relative luminance; if it exceeds the cap, scale the
  color toward black (proportional RGB scale, hue preserved) until
  its luminance equals the cap. The cap is ONE named constant in
  `arc_stage.dart`; starting value **0.216** (the fix round's
  measured max). Petra ratifies the exact cap at the gate.
- Per-arc alpha formula unchanged in form:
  `min(0.30, 0.028 + log10(n) × 0.055) × density` (Home band 0.30 →
  0.0084–0.09). Adjust only if the measured envelope below fails,
  minimally, with the new numbers stated in the report.
- **Envelope at Home parameters** (1200×500 stage, lo 0, hi 1188,
  band 0.30, arcs only, labels off — the fix-round evidence method):
  mean ≤ 0.13, p99 ≤ 0.22, max ≤ cap, fraction above 0.9 luminance
  = 0. Fix-round gold-only reference: 0.103 / 0.196 / 0.216 / 0.000.
  Original blowout reference: 0.593 / 1.000 / 1.000 / 0.596.
